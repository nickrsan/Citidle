# Citidle - Zoom Fix and Improvements Summary

**Date**: 2026-05-07 22:15
**Input Prompt**: Fixing broken rendering after zoom, adding tests for zoom, and adding a zoom reset button.

## Understanding of the Issue
The initial issue was that zooming felt "broken" (likely because it didn't zoom towards the mouse and might lose the city from the view) and there was no way to reset the view. Additionally, some tests were failing due to configuration mismatches.

## Actions Taken
1.  **Zoom Logic Improvement**:
    *   Updated the `wheel` event handler in `src/main.js` to implement "zoom-to-mouse" behavior. This ensures that the point on the grid under the cursor stays under the cursor while zooming.
    *   Imported `ISO` into `src/main.js` to correctly calculate tile dimensions for camera centering.
2.  **Zoom Reset & Camera Centering**:
    *   Added a "🔍 Reset" button to the HUD in `index.html`.
    *   Implemented `centerCamera()` in `src/main.js` which calculates the center of the unlocked map area and aligns it with the screen center.
    *   The reset button sets zoom to 1.0 and calls `centerCamera()`.
3.  **Test Fixes & Additions**:
    *   Added math tests to `tests/renderer.test.js` to verify that zooming and camera offsets correctly transform grid and screen coordinates.
    *   Added a Cypress E2E test `cypress/e2e/zoom_ui.cy.js` to verify the Zoom Reset button and mouse wheel interaction.
    *   Updated existing Cypress tests (`gameplay.cy.js`, `research_ui.cy.js`, `zoning_scaling.cy.js`) to match the actual game configuration values in `src/config.js` (e.g., higher expansion costs and zone scaling factors).
4.  **Documentation**:
    *   Updated `FEATURES.md` to include Zoom-to-mouse and Zoom Reset button.
    *   Updated `documentation/USER_GUIDE.md` with instructions on how to use the new zoom features.
    *   Updated `documentation/DEVELOPER_GUIDE.md` with technical details about the camera and zoom implementation.
